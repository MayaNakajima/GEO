# AI出現モニタリング｜メンバー向けセットアップ手順（v2）
## 株式会社オンワードコーポレートデザイン

BOX上の共有フォルダから直接実行する方式です。APIキーは共有フォルダの `.env` に設定済みのため、
各メンバーは**パッケージの導入（初回のみ）→ 実行**の2ステップで使えます。
（結果を見るだけの方は「D. 結果の見方」だけ読めばOKです）

共有フォルダ：`%USERPROFILE%\Box\事業推進Div□\DX推進課\生成AI\monitoring`
　※ `%USERPROFILE%` は各自の `C:\Users\<自分>` に自動で置き換わります（そのまま貼り付けOK）。

---

## 事前に用意するもの

- **Python（Anaconda 推奨）**：未インストールなら Anaconda（anaconda.com）を導入。
- 上記BOXフォルダへのアクセス権（無い場合は管理者：中島 まで）。

---

## A. 必要パッケージのインストール（初回のみ）

コード自体はBOXにありますが、**動かすためのパッケージは各自のPCに入れる**必要があります。

1. スタートメニューから **「Anaconda Prompt」** を開く。
2. 次を実行：
   ```
   cd /d "%USERPROFILE%\Box\事業推進Div□\DX推進課\生成AI\monitoring"
   pip install -r requirements.txt
   ```
   ※ これで `anthropic` や `truststore`（社内SSL対策）などが入ります。

---

## B. 実行する

**方法1（推奨・確実）**：Anaconda Prompt で
```
cd /d "%USERPROFILE%\Box\事業推進Div□\DX推進課\生成AI\monitoring"
python run.py
```
→ メニューが開きます。番号を選ぶだけ（1:GUI起動／2:接続診断／3:データ全削除／4:選択削除）。

**方法2（ダブルクリックしたい場合・各自1回だけショートカット作成）**
1. デスクトップで右クリック →「新規作成」→「ショートカット」
2. 「項目の場所」に次を貼り付け（`python.exe` の場所は自分のAnacondaに合わせる。例：`C:\work\anaconda_install`）:
   ```
   "C:\work\anaconda_install\python.exe" "%USERPROFILE%\Box\事業推進Div□\DX推進課\生成AI\monitoring\run.py"
   ```
3. 名前を付けて「完了」。以降このショートカットをダブルクリックでメニューが開きます。
   （batは使いません。cmdの関連付け問題やcmd画面を避けられます）

**GUIの操作**：メニューで「1」を選ぶ → ブラウザで `http://127.0.0.1:8765/` が開く
（開かなければ表示URLを手動で貼り付け）。
1. 「観測するLLM」＝ Claude Sonnet 5（既定でチェック済）。
2. まず動作確認：「ドライラン」ON・「事業ドメインを絞る」→ C5 で「▶ 実行する」。画面が流れれば正常。
3. 本番：**ドライランのチェックを外し**、必要な範囲・回数で実行。
4. 終了：黒いウィンドウ（またはメニュー）を閉じる（自動実行もそこで停止）。

## C. 実行時の注意

- **課金**：実行するとClaudeのAPI利用料が発生します（1回=78問で目安 約98円）。まずは範囲を絞って確認を。
- **データは共有**：BOXフォルダで直接実行するため、結果（`data/`）は共有フォルダに保存され全員が見られます。
  **複数人が同時に実行すると競合する**ことがあるので、実行タイミングは分ける／担当者を決める運用がおすすめです。
- **自動実行**：GUIの黒いウィンドウ（またはメニュー）を開いている間だけ有効。閉じると止まります。

## D. 結果の見方

- 実行後、GUI右側「レポート」→ **「📊 ダッシュボードを開く」**。
- **時系列トレンド**：出現率の推移・前回比・施策への示唆。
- **タイミング詳細**：同一タイミングを複数回実行したときの平均±SD（ブレ）・安定していない質問。

---

## E. うまく動かないとき

- `python が見つからない` → Anaconda未導入／PATH未設定。Anaconda Prompt から実行する。
- `ModuleNotFoundError` → A章の `pip install -r requirements.txt` を実行。
- `SSL / certificate verify failed / Connection error` → `pip install truststore` を実行（社内CA対策）。
- batをダブルクリックしても動かない → 上記「方法1（python run.py）」か「方法2（ショートカット）」を使う。
- 詳細は `運用手順書_v1.md` の「トラブルシューティング」を参照。
